About graphviz-ts

  • Zero dependencies - Pure TypeScript, no external libraries needed
  • Runs anywhere - Works in browser and Node.js
  • DOT language support - Parses standard Graphviz DOT format
  • Multiple layouts - dot, neato, fdp, circo, twopi
  • SVG output - Clean, scalable vector graphics
  • Easy to use - Simple API: Graphviz.dot(dotString)
